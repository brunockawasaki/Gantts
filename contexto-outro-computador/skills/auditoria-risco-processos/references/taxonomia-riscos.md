# Taxonomia de riscos

Códigos para organizar e comparar achados. Não substituem critério corporativo especializado —
são só rótulo, não fonte de autoridade normativa.

formatação QLD.002) não devem ser reexecutados aqui — ver a seção de fronteira no `SKILL.md`. Use
DOC-xx nesta skill só para o **ciclo de vida** (vigência real, quem é dono, se está publicado) e
não para a completude estrutural.
